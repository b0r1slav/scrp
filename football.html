HOW IT WORKS

Reading the streaks

  • Each completed league match is counted for both teams.
  • Parity is based on combined goals: a 2–1 match has 3 total goals, so it is odd.
  • Strike counts consecutive matches with the same parity as the team's latest match.
  • Counts are season-to-date, up to the team's latest 50 completed matches.
  • League results come from football-data.org and refreshes are cached for 15 minutes.

Set the FOOTBALL_DATA_TOKEN environment variable on the server to enable live data. The free API tier provides current season data.
