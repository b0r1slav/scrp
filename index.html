HOW IT WORKS

Reading the streaks

  • Each set score is added together. 6-3 6-4 is 19 games: odd.
  • Strike counts consecutive results of the latest match’s parity.
  • Only completed singles matches are counted, up to the latest 20.
  • Retirements / abandoned matches with a final set below 6 games are skipped.
